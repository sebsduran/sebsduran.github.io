Privacy Policy

Last updated: October 1, 2026

This policy covers Media Manager, a private tool that I, Sebastian Duran, use to manage my own channel, Sebs Duran (@SebsDuran). I am an individual creator and the tool's only user. You must agree to this policy before using Media Manager.

1. Media Manager uses YouTube API Services

Media Manager uses YouTube API Services to read and edit data on my own channel. By using Media Manager you are also subject to the YouTube Terms of Service and the Google Privacy Policy at http://www.google.com/policies/privacy.

2. What data it accesses

After I sign in with my Google account and grant the YouTube permission (https://www.googleapis.com/auth/youtube.force-ssl), Media Manager accesses:

  • My channel's video details: titles, descriptions, tags, privacy status, publish dates, durations and public statistics such as views, likes and comment counts.
  • My channel's playlists and the videos in them.
  • Caption tracks on my own videos.
  • Public comments that viewers leave on my own videos, including the commenter's display name and the comment text, so I can collect song requests.
  • An OAuth access token and refresh token for my account.

It does not access other channels' private data, does not collect YouTube passwords, and does not download video or audio content.

3. How the data is used

  • To plan and make edits to my own videos: titles, descriptions, tags and chapter timestamps.
  • To change my own unlisted videos to public on a schedule I approve.
  • To create and organize playlists on my channel.
  • To make a private list of song requests from comments on my videos.

Data is used only for these purposes. The tool always tells me what it will change on YouTube, and I approve changes before they are written.

4. Sharing

I do not sell, rent or share this data with anyone. It is not shared with other internal or external parties, and it is not used for advertising. Media Manager does not let third parties serve content or ads.

5. Storage, the 30 day rule and deletion

  • Data is stored only on a private machine I control and protected with standard access controls and encrypted connections (HTTPS) to Google.
  • Public statistics (such as view, like and comment counts) may be kept longer while my authorization is active, and the tool checks at least every 30 days that it is still authorized and that the videos still exist.
  • All other YouTube data (such as titles, descriptions, tags, caption text, playlist details, commenter names and comment text) is refreshed or deleted within 30 days of when it was retrieved.
  • OAuth tokens are stored only for as long as needed to run the tool.
  • If a viewer asks me to delete stored data about them, such as a comment saved in my song request list, I delete it as soon as possible and within 7 days. Ask using the contact below.
  • Deleting data stored by Media Manager does not delete anything on YouTube. To change or delete data on YouTube, use YouTube or YouTube Studio.

6. Cookies and device data

Media Manager and this website do not use cookies, analytics, tracking pixels or similar technology, and they do not store or read information on visitors' devices.

7. How to revoke access

You can revoke Media Manager's access to a Google account at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, Media Manager stops using that account and deletes the data it stored under that permission as soon as possible and within 7 days. If a token can no longer be refreshed, the related stored data is deleted within 30 days at the latest.

8. Children

Media Manager is not directed to children.

9. Changes

If this policy changes, I will update the date at the top of this page. If the tool starts using data in a new way, I will update this policy first.

10. Contact

Questions or complaints about this policy or my privacy practices: Sebastian Duran, iamsebsduran@gmail.com
